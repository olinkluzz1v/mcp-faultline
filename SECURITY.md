# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately using
[this repository's GitHub reporting form](https://github.com/olinkluzz1v/mcp-faultline/security/advisories/new).
You can also select **Security and quality → Report a vulnerability** on GitHub.
Do not disclose vulnerability details in public issues or pull requests.

Include:

- The affected version or commit and relevant environment details.
- A minimal reproduction, with expected and observed behavior.
- The potential impact and any relevant logs, with credentials, tokens and
  personal data removed.

Use the private report for follow-up discussion.

## Support

MCP-Faultline is at an early stage. No response or fix timeline or release support
period is guaranteed. Fixes may require updating to a newer commit or release;
older releases have no guaranteed security backports.
